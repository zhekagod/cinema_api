# 🎬 Cinema Tickets API

Backend-сервис для системы бронирования киносеансов, реализованный на FastAPI с использованием PostgreSQL и SQLAlchemy ORM.

Проект демонстрирует базовую архитектуру REST API с авторизацией, CRUD-операциями и бизнес-логикой бронирования мест.

---

## ⚙️ Технологический стек

- Python 3.12+
- FastAPI
- SQLAlchemy (ORM)
- PostgreSQL (Docker)
- Pydantic / Pydantic Settings
- JWT (JSON Web Token)
- Pandas (визуализация данных)
